# 📍 토글(Toggle) 서비스 요구사항 명세서 (MVP)

## 🚀 실시간 영업 상태 기반 지도 플랫폼

---

# 1. 서비스 개요

## 1.1 서비스명  
**토글(Toggle)**

## 1.2 서비스 정의  

토글은 자영업 매장의 **실시간 영업 상태를 사용자에게 제공하는 위치 기반 웹앱 서비스**이다.  

사용자는 현재 실제로 방문 가능한 매장을 빠르게 확인할 수 있으며,  
로그인 시 즐겨찾기 및 나만의 지도를 통해 개인화된 장소 아카이브를 만들고 공유할 수 있다.

---

## 1.3 서비스 기획 배경  

기존 지도 서비스는 고정된 영업시간 정보를 기반으로 하여 실제 상황과 불일치하는 문제가 있다.

### 📌 문제 상황

- 영업 중으로 표시되지만 실제는 마감
- 브레이크타임 미반영
- 임시휴무 정보 누락

### 💡 해결 방향

- 실시간 매장 상태 반영
- 점주 직접 업데이트 구조
- 로그인 없이도 사용 가능한 지도 탐색
- 개인화 및 공유 기능 제공

---

# 2. 서비스 목표

## 2.1 핵심 목표

- 사용자가 **지금 방문 가능한 매장**을 정확하게 확인할 수 있도록 한다.
- 사용자의 현재 위치와 실시간 상태를 기반으로 **지금 갈 수 있는 최적의 매장을 추천한다.**
- 로그인 없이도 핵심 탐색 기능을 제공한다.
- 로그인 사용자에게 개인화 기능을 제공한다.
- 점주가 쉽게 매장 상태를 업데이트할 수 있도록 한다.
- 길찾기는 외부 지도 서비스와 연동한다.

---

## 2.2 핵심 가치

- **정확성**: 실시간 상태 기반 정보 제공  
- **편의성**: 로그인 없이 즉시 사용 가능  
- **개인화**: 나만의 지도 및 저장 기능  
- **공유성**: 사용자 간 지도 공유

## 메모
- 이번 세션의 핵심은 관리자 승인을 "사업자 검증"과 "매장 매핑"으로 분리한 것이다.
- 카카오 매핑은 현재 실제 REST 호출 기반 골격까지 연결됐고, 운영 정확도는 주소 비교 규칙에 계속 좌우된다.
- 관리자 브라우저 자동화는 로그인 버튼 클릭 후 전환 캡처가 안정적이지 않아, 빌드/테스트/API 검증을 함께 사용했다.
- 개발 서버는 `JWT_SECRET='local-dev-jwt-secret-key-12345678901234567890' ./gradlew bootRun` 기준으로 재기동해 최신 시드를 반영했다.
- 현재 후보 조회 `500`의 직접 원인은 카카오 Local API 권한 미설정이다. 실제 응답은 `App(toggle) disabled OPEN_MAP_AND_LOCAL service.`였다.
- `KakaoPlaceClient`는 외부 API 오류를 잡아주지 않아 현재는 카카오 권한/쿼터/업스트림 오류가 전부 `INTERNAL_SERVER_ERROR`로 번진다.
- 개발 시드에서 수동으로 `application.approve(...)`만 호출한 신청들은 링크가 있어도 `mappingStatus`를 갱신하지 않아 운영 화면에서 헷갈릴 수 있다.
- 현재 승인 API는 `businessVerified=true`가 있어야 하고, 내부 주소 자동 매핑이 성공해야만 통과한다.
